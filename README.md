# 文件抽屉 · macOS File Drawer

一款极简的 macOS 桌面工具：启动后，屏幕右侧滑出一个半透明「抽屉」，可以把文件/文件夹随手放进去暂存，需要时再拖出来继续使用。

用 **Swift + AppKit(NSPanel) + SwiftUI** 实现，无任何第三方依赖。

## 设计

视觉语言以「玻璃 + 靛紫身份色」为核心，克制但有辨识度：

- **身份色**：全 app 统一的靛紫渐变（`#6C5CE7 → #A05CE6`），集中定义在 `DrawerTheme`——
  头部图标底、计数徽章、选中指示条、搜索高亮、拖放反馈全部从同一套 token 取色，
  刻意避开系统蓝，让抽屉一眼可辨。
- **材质**：`NSVisualEffectMaterial.ultraThin` 毛玻璃抽屉身，贴屏幕边缘的一侧无圆角，
  另一侧 22pt 大圆角 + 发丝高光；顶部一抹极淡的靛紫光晕向下淡出，是抽屉的"品牌印记"；
  贴边对侧中部的三枚刻度线是"抽屉拉手"，悬停点亮为渐变并微微放大。
- **瓷片**：图片/视频展示**真实缩略图**（ImageIO 降采样 / AVFoundation 抽帧，后台线程）；
  其余类型用低饱和底色 + 同系深色符号的着色容器（仿系统标签），拒绝彩虹渐变色块。
- **排版**：名称 13pt Medium + 元信息 11pt 三级灰（大小 · 相对时间），
  层级只靠字重与灰度表达；计数徽章用等宽数字，变化时数字滚动。
- **动效**：收起/展开是真实的弹簧物理（`WindowSpringAnimator` 数值积分驱动窗口 frame，
  约 3% 过冲回弹，像抽屉拉到头轻轻一顿）；抽屉展开时条目从贴边侧**错峰滑入**；
  新拖入的条目行底扫过一道品牌色光；拖放悬停时描边**虚线像传送带一样流动**；
  空态虚线环缓慢旋转、圆盘呼吸浮动；悬停操作钮错峰滑入、按钮按压缩放；
  选中行有前缘渐变指示条；键盘 ↑↓ 移动选中时行自动滚动跟随。
  所有动画都是 Spring/缓出，时长克制。

## 功能

- 🗂 **拖入暂存**：从访达（或其它应用）把文件、文件夹拖到抽屉里；支持一次多选拖入。
- ✋ **拖出取回**：按住条目往抽屉外拖即可——落到 Finder 是拷贝真实文件，放到邮件、聊天窗口等也认。
- 👁 **空格快速预览**：单击条目选中后按 **空格**，抽屉内弹出原生 QuickLook 卡片——
  视频直接播放、PDF 可翻页、图片支持缩放；**↑↓** 实时切换、**⏎** 打开、**Esc** 关闭。
- 🔍 **搜索与排序**：点放大镜或 **⌘F** 呼出搜索胶囊，边输边滤、命中片段高亮；
  排序支持「最近加入 / 最早加入 / 名称 A–Z / 类型分组」，选择会记住。
- 🚪 **收起成边条**：点左缘拉手把抽屉缩成贴右缘的 42×190 窄边条（毛玻璃竖条 + 托盘图标 + 计数），
  点击边条展开；直接把文件拖到边条上会自动展开接住。菜单栏菜单同样可切换。
- ⚡️ **启动即滑入**：应用启动后抽屉从屏幕右缘平滑抽出（非激活面板，不抢当前焦点）。
- 🔒 **不打扰**：浮动于普通窗口之上、全空间可见，但点击它不会激活前台应用。
- 👆 **快捷操作**：双击打开文件（可在设置改为单击打开）；悬停行出现「在访达中显示 / 另存为 / 移除」；
  右键菜单含「拷贝路径」「移动到文件夹…」等全部操作；头部「+」可从对话框导入。
- ⌫ **键盘移除**：Delete 键移除选中条目。
- 🧲 **按住清空**：垃圾桶按钮需按住约 0.65 秒进度环走满才清空，避免误触。
- 💾 **自动记忆**：条目列表与排序偏好持久化到 UserDefaults，重启原样恢复（已删除的源文件自动清理）。
- 🧹 **暂存维护**：可配置过期自动清理（1/7/30 天）与容量上限（20/50/100 条，超出淘汰最早加入），设置里可一键清理失效条目。
- 🍃 **菜单栏图标**：托盘图标菜单提供 显示/隐藏抽屉、导入、清空、设置、退出。
- ⚙️ **设置面板**：点头部齿轮、菜单栏「设置…」或按 **⌘,** 打开，四组配置即时生效：
  - **通用**：启动时展开/收起、启动时是否清理已不存在的文件、默认排序、单击直接打开、
    自动清理过期条目、容量上限、当前条目数与一键清理；
  - **外观**：浅色/深色/跟随系统、抽屉宽度（280–420pt）、占屏高度比例、垂直停靠位置、
    停靠边缘（左/右）、毛玻璃浓度（超薄/薄/厚/超厚）、紧凑列表、显示大小/时间/缩略图；
  - **行为**：拖文件到边条上自动展开、拖出文件后自动收起、清空后自动收起、
    切换到其他应用时自动收起、面板层级（浮动/普通）；
  - **快捷键**：全局热键（Carbon RegisterEventHotKey），任意应用前台时展开/收起抽屉，
    默认 ⌥Space，点按键框录制新组合（必须含 ⌘/⌥/⌃ 修饰键）。

## 键盘一览

| 按键 | 作用 |
| --- | --- |
| 单击条目 | 选中（并让抽屉接收键盘；设置可改为直接打开） |
| 空格 | 开/关选中条目的快速预览 |
| ↑ ↓ | 上下移动选中（预览打开时同样生效） |
| ⏎ | 打开选中文件 |
| Delete | 移除选中条目 |
| Esc | 关闭预览 / 取消选中 |
| ⌘F | 呼出并聚焦搜索框 |

> 键盘只在抽屉持有焦点时接管（单击任意条目即可）；正在搜索框输入时按键完全放行。

## 构建 & 运行

```bash
./make_app.sh
open build/FileDrawer.app
```

或开发调试：

```bash
swift build            # 编译调试版
swift test             # 运行单元测试（含拖拽往返一致性测试）
```

要求：macOS 14+，Xcode 命令行工具（`make_app.sh` 会使用 `/Applications/Xcode.app`）。

## 使用方法

| 操作 | 方式 |
| --- | --- |
| 放入 | 把文件从 Finder 拖进抽屉；或菜单栏图标 →「导入文件…」 |
| 取回 | 按住卡片拖出到 Finder / 其它应用窗口 |
| 打开 | 双击卡片（设置可改为单击打开） |
| 定位 | 悬停卡片点「folder」图标 |
| 拷贝路径 | 右键卡片 →「拷贝路径」 |
| 归位整理 | 右键卡片 →「移动到文件夹…」（文件移动，条目改指新位置） |
| 移除 | 悬停卡片点「✕」，或选中后按 Delete |
| 清空 | 菜单栏图标 →「清空抽屉」 |

## 实现要点

- **抽屉窗口**：无边框 `NSPanel(styleMask: [.borderless, .nonactivatingPanel])`，
  `level = .floating` + `canJoinAllSpaces`，右缘对齐、左侧大圆角 +
  `.ultraThinMaterial` 毛玻璃底；显隐动画由 `WindowSpringAnimator` 用弹簧物理
  逐帧移动 frame（欠阻尼，带轻微过冲回弹），收起/展开都有真实的"抽屉手感"。
- **拖出**：`onDrag { item.dragProvider() }`。provider 同时注册
  *文件表示*（接收端拿到真实文件副本）与 *file-url 数据表示*（通用地址语义）。
- **拖入**：`.onDrop(of: [.fileURL], delegate:)`，逐个解析 provider
  （优先 `loadObject(ofClass: URL.self)`，兜底原始数据），批量入列并去重。
